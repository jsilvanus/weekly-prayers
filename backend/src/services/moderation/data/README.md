# Name data for the moderation matcher

`names.json` is read by `../names.js`. It is generated by
`backend/scripts/build-name-list.js` (no dependencies) from:

1. `backend/scripts/moderation-names/seed.json`: hand-made lists of common Finnish,
   Swedish and English first names and Finnish/Swedish/English surnames, plus an
   `ambiguous` list of ordinary words that are also names (toivo, rauha, armas, hope,
   grace, fred ...). These were written by hand from general knowledge. They are NOT a
   statistical source and are NOT complete.
2. Optional DVV statistics CSV files passed with `--first` / `--last` (see the script header).

## Intended DVV use (when the download is possible)

1. Download the first-name and surname statistics from avoindata.fi (record the exact URL and date here).
2. Convert XLSX to CSV if needed (any tool; the build script itself reads CSV only).
3. `node scripts/build-name-list.js --first <first.csv> --last <last.csv> --min-count 200`
4. Record the licence and source in this file, then re-run `npm test` and the moderation eval.

Only population-level frequency counts are used. No individual person data is involved.

## Limits

The matcher is rule-based. Names that are not in the lists are not found. The later model
tier is meant for those cases. Surname inflection is only partly covered (see `../names.js`).
